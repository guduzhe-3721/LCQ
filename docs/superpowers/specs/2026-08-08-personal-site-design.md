# 个人文章与资源库网站设计

## 目标

建立一个以中国大陆访客为主的个人网站：任何访客可阅读文章和浏览资源目录；完成邮箱验证并登录的用户可下载资源。第一版支持自己的文件与开源软件，不支持普通用户上传。

网站采用明亮现代的视觉风格：留白、圆角卡片、清晰的资源标签，文章和资源库同等突出。

## 架构

- Web 应用部署在托管前端/应用平台；使用 Next.js 作为全栈网站框架。
- 托管数据库保存用户、文章、资源、下载记录和管理日志；认证采用邮箱注册、验证、登录与密码重置。
- 文件存放在独立对象存储。默认适配腾讯云 COS 香港区和 CDN，以免备案阶段服务大陆访客；存储接口隔离，后续可迁移至阿里云 OSS 或其他兼容对象存储。
- 应用服务端在验证登录用户和资源状态后，签发短时有效的对象存储下载链接；对象存储的真实路径不在前台页面暴露。

## 用户体验与功能

### 公开前台

- 首页提供最新文章、精选资源、标签入口和站点介绍。
- 文章支持标签、全文搜索、目录、代码块和移动端阅读。
- 资源目录支持搜索、标签/类别筛选和资源详情页。详情页展示介绍、版本、文件大小、更新日期、原始来源、开源许可证和 SHA-256 校验值。
- 未登录访客可查看详情，但点击下载时进入登录或注册流程。

### 账号与下载

- 用户通过邮箱注册，完成验证后才具备下载权限；支持登录、登出和密码重置。
- 登录用户点击下载后，服务端检查账号会话、资源是否发布且可下载，再生成几分钟有效的一次性下载链接，并写入下载记录。
- 下载链接过期时提示用户回到资源页重新获取；账号验证、登录和下载接口进行限流。

### 管理与发布

- 管理后台仅站长可用，支持文章和资源的新建、编辑、预览、发布、下架与删除。
- 文章编辑器以 Markdown 为主，保留所见即所得预览；本地 Markdown 导入读取 front matter 中的标题、摘要、标签、发布日期和封面。导入先预览验证，默认新建草稿而不覆盖既有文章。
- 资源发布流程为：上传文件至对象存储 → 填写并验证元数据 → 自动计算或录入 SHA-256 → 保存为草稿 → 发布。上传或校验失败时不允许发布。
- 软件与文件只发布站长拥有分发权的内容或开源软件；资源必须填写来源与许可证，后台保留操作日志。

## 数据与接口边界

- `Article`：slug、标题、摘要、Markdown 正文、标签、封面、状态、发布时间与更新时间。
- `Resource`：slug、标题、描述、类别、版本、文件名、大小、对象键、SHA-256、来源 URL、许可证、状态与发布时间。
- `User`：邮箱、验证状态、角色、认证元数据与创建时间；角色只有普通用户和管理员。
- `Download`：用户、资源、签发时间、过期时间和结果，用于审计和基础统计。
- 公开读取接口仅返回已发布的文章/资源；管理接口要求管理员身份；下载接口要求已验证的登录用户并返回短时签名 URL。

## 可靠性、安全与验收

- 对象存储上传失败、元数据校验失败或哈希缺失时，资源保留为草稿且向管理员显示可处理错误。
- 下架资源立即停止新的下载链接签发；删除操作需二次确认，并保留日志记录。
- 页面、资源详情和下载接口采用权限测试；不允许通过猜测对象键或复用过期链接绕过登录要求。
- 验收覆盖：邮箱注册/验证/登录/重置密码，文章后台发布与本地 Markdown 导入，资源上传/发布/下架，未登录下载拦截，签名链接到期，管理员权限隔离，异常状态提示，以及常见桌面和移动屏幕的阅读与下载流程。

## 上线前提

- 首版默认使用未备案域名和香港区服务；若未来申请大陆备案，可把网站和下载加速迁往大陆节点。
- 需在实施时配置域名、邮件发送服务、数据库、对象存储、CDN 和管理员邮箱。正式上线前需完成隐私政策、服务条款和联系/下架渠道页面。
